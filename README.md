# Helping-Hands - Donation Platform

A Java-based desktop application that connects donors with people in need for essential items like clothes, books, and food.

## Features
- User Registration & Login
- Donate Items with Images
- Browse & Request Donated Items
- Admin Panel to Manage Donations
- Profile Management

## Tech Stack
- **Language:** Java (Core Java)
- **UI:** JavaFX, CSS
- **Database:** MySQL with JDBC
- **Concepts:** OOP (Inheritance, Polymorphism), Collections, Exception Handling
- **Tools:** Git, GitHub

## How to Run
1. Clone repo: `git clone https://github.com/omroman1/Helping-Hands.git`
2. Import in IntelliJ / Eclipse
3. Setup MySQL DB and update `ConnectionProvider.java`
4. Run `HomePage.java`
